1. On the slides there is a custom implementation of the DictionaryInterface. However, in this exercise you can use its ready-made implementations HashMap or Hashtable in the Java API.

- A hashmap (or hashtable) is a data structure that stores key-value pairs and allows for fast data retrieval based on the key. 
- It uses a hash function to convert the key into an index in an array, where the corresponding value is stored. 
- This enables average-case constant time complexity O(1) for lookups, insertions, and deletions.
